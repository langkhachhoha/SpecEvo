# Best discovered programs

The highest-scoring programs each method produced, kept for the reproducibility
statement in the paper's appendix. These are **outputs**, not inputs — nothing in
the search pipeline reads them.

```
best_programs/<task>/<method>/best.py        the evolved program
best_programs/<task>/<method>/best_circles.npy   the solution it constructs (packing tasks)
```

Method keys: `specevo` (ours), `oe` (OpenEvolve), `gepa` (GEPA), `ada` (AdaEvolve),
`evox` (EvoX).
